分析一下pwn题目调试的思路， 就拿这个举例好了

```
#include <stdio.h>
#include <stdlib.h>

void return_input()
{
	char array[30];
	gets(array);
	printf("%s\n", array);
}

int main()
{
	return_input();
	return 0;
}

```
