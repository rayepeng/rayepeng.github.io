## 转为灰度图
![zuoye.jpg](https://upload-images.jianshu.io/upload_images/10651191-0753e51ffc4471eb.jpg?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

转为bmp格式
（简书不准上传bmp格式的图片
![clone.bmp](https://upload-images.jianshu.io/upload_images/10651191-a8a3242e73a1704e.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

## 代码
```
img=imread('zuoye.jpg');
imwrite(img, 'clone.bmp');
img2=imread('clone.bmp');
gray1=rgb2gray(img);
gray2=rgb2gray(img2);
imwrite(gray1, 'grayjpg.jpg','jpg')
imwrite(gray2, 'graybmp.bmp','bmp')
```

## 使用jpg压缩bmp格式的图片
涉及到一点`imwrite`函数，要查文档

```
%用jpg压缩图片
imwrite(img2,'compression90.jpg','quality',90);
imwrite(img2,'compression80.jpg','quality',80);
imwrite(img2,'compression70.jpg','quality',70);
imwrite(img2,'compression50.jpg','quality',50);
imwrite(img2,'compression30.jpg','quality',30);
imwrite(img2,'compression10.jpg','quality',10);
```
