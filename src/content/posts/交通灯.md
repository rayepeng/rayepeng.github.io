m0状态代表A和B都是红灯

```verilog
always @(posedge clk1 or negedge rst) begin
  if (!rst) begin
    counter <= 5'd30;  //复位信号，保持红灯亮计数器赋初值30
    mode <= m0;
  end else begin
    counter <= counterNext;
    mode <= modeNext;
  end
end
```

如果m0状态的时候输入的keyA和keyB为00，也就是说正常情况下保证主干道绿灯亮，支干道红灯亮
```verilog
      case (state)
        s0: begin
          modeNext <= m1;
          counterNext <= 5'd30;
        end
```
将counter和1‘b0拼接在一起
```verilog
assign counterExt = {1'b0, counter};
```

根据mode和counterExt进行转换
```verilog
always @(mode or counterExt) begin
  case (mode)
    m0: begin counterA <= counterExt; counterB <= counterExt; end
    m1: begin counterA <= counterExt - 3'd4; counterB <= counterExt; end
    m2: begin counterA <= counterExt; counterB <= counterExt; end
    m3: begin counterA <= counterExt; counterB <= counterExt - 3'd4; end
    m4: begin counterA <= counterExt; counterB <= counterExt; end
    default: begin counterA <= counterExt; counterB <= counterExt; end
  endcase
end  
```

针对counterA和counterB来说
time0和time1，time2和time3

assign ledAOut = {ledA[2], ledA[1] & clk1, ledA[0]};
