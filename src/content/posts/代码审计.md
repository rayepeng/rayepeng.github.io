#### 基础知识

##### == 与 === 不一样
php中==不同于===，===在进行比较前先判断等式两边类型是否相同，而==会先将两边类型转化成相同再比较．[php类型比较表](http://php.net/manual/zh/types.comparisons.php)．

所以这就是PHP弱类型
```
'' == 0 == false '123' == 123             //'123'强制转换为123 
'abc' == 0　        //intval('abc')==0 
'123a' == 123            //intval('123a')==123 
'0x01' == 1             //被识别为十六进制
'0e123456789' == '0e987654321'　　//被识别为科学计数法 
[false] == [0] == [NULL] == [''] 
NULL == false == 0 
true == 1
```
激进一点理解为：
* == 只要是值相同就行了
* === 才会去比较类型
