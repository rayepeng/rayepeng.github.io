要求:
1. 通常保持主干道绿灯亮，支干道红灯亮，支干道来车时，转为主干道红灯亮，支干道绿灯亮
2. 绿灯转红灯要闪烁3秒
3. 两个方向都有车时，红绿灯间隔30s转换一次
4. 复位功能

考虑状态
灯量的情况有以下几种
A red B red
A green B red
A yellow B red
A red B green
A red B yellow

(排除掉 A green B green 不可能两灯都是绿
A green B yellow 因为B之后会变绿，也不可能
A yellow B green  那么之前的状态肯定是A green B green 也不可能
A yellow B yellow 不可能两灯都是黄灯 
所以定义5中不同的状态

从 A green B red -> 支干道来车 A yellow B red -> A red  B green 
如果这时候按下复位键 A red B green -> A red B yellow -> A red B red
基本上的状态转换就这几种

![状态转化图](https://upload-images.jianshu.io/upload_images/10651191-befd67309c42cb68.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

```verilog
// A red and B red.
parameter mode0 = 3'd0;
// A green and B red.
parameter mode1 = 3'd1;
// A yellow and B red.
parameter mode2 = 3'd2;
// A red and B green.
parameter mode3 = 3'd3;
// A red and B yellow.
parameter mode4 = 3'd4;
```

对于按键的考虑，由于有一个默认情况是主干道绿灯主干道红灯
```verilog
always @(keyA or keyB) begin
  case ({keyA, keyB})
    2'b00: state <= s0;
    2'b10: state <= s0;
    2'b01: state <= s1;
    2'b11: state <= s2;
    default: state <= s0;
  endcase
end
```

对于计数的要求

time1 time2 分别是A的个位和十位
time3 tme4 分别是B的个位和十位

```verilog
always @(counterA) begin
  if (counterA <= 6'd9) begin
    time2 <= counterA[3:0];
    time3 <= 4'd0;
  end else if (counterA <= 6'd19) begin
    time2 <= counterA - 6'd10;
    time3 <= 4'd1;
  end else if (counterA <= 6'd29) begin
    time2 <= counterA - 6'd20;
    time3 <= 4'd2;
  end else begin
    time2 <= counterA - 6'd30;
    time3 <= 4'd3;
  end
end
```
为了显示十位，通过if判断减去10或者20得到十位

B的计数是一样的

clk1k 用来扫描数码管

clk1 用来使黄灯闪烁同时控制计数器和模式的转换

```verilog
assign ledAOut = {ledA[2], ledA[1] & clk1, ledA[0]};
assign ledBOut = {ledB[2], ledB[1] & clk1, ledB[0]};
```

黄灯闪烁是通过去&一个时钟信号来完成的
