## 快捷键

`ctri + D` 选择一个单词， 如果连续按下去会多次选择文件中出现的全部单词， 然后光标会分成很多个部分， 方便同时修改多个单词。

![](https://upload-images.jianshu.io/upload_images/10651191-5f4e9b4c1b2d89ed.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

`alt+F3` 功能和 ctrl + D 的功能类似

`ctrl + L `一次选择一行， 连续使用 `ctrl + L` 时， 再按下 `ctrl + shift + L`就会变成列编辑。
所以我们可以直接全选所有的文件， 然后`ctrl+ shift + L`就会开始列编辑模式。

`ctrl + Alt + L `也可以变成列编辑模式

`ctrl + F2 `设置书签

`ctrl + K + U `转大写
`ctrl +Ｋ＋Ｌ｀转小写

`ctrl + ALt + L` 选中几行进入列编辑模式
