# 过桥问题
首先来看一个过桥问题
>有一座桥，南北向，都有入口出口。
1.假设该桥上每次只能有一辆车行驶，试用信号灯的P、V操作实现交通管理。
2.假设该桥上不允许两车交会，但允许同方向多个车一次通过（即桥上可有多个同方向行驶的车）。试用信号灯的P、V操作实现桥上交通管理。

这应该属于读者和写者问题， 但是又不完全是， 因为这种情况下， 读者和写者(我们暂且这么说) 都可以连续的读和写

定义信号量
```
int countSN=0;

int countNS=0;

semaphore mutexSN=1;

semaphore mutexNS=1;

semaphore bridge=1;
```

从StoN的
```
StoN
{
	p(mutexSN); //进行计数之前先上锁
	if(countSN == 0)
		//检测自己是否是第一个从StoN的人
		p(bridge);
	countSN++; //这个变量的修改是互斥的
	V(mutexSN);

	//过桥
	
	//继续修改countSN
	P(mutexSN);
	countSN--;
	/*
	如果是从StoN的最后一个人， 就可以释放桥这个资源了
	 */
	if(countSN == 0)
		V(bridge);
	V(mutexSN);

}

```
其实从NtoS的代码是很类似的

```
NtoS
{
	p(mutexNS); //进行计数之前先上锁
	if(countNS == 0)
		//检测自己是否是第一个从NtoS的人
		p(bridge);
	countNS++; //这个变量的修改是互斥的
	V(mutexNS);

	//过桥
	
	//继续修改countSN
	P(mutexNS);
	countNS--;
	/*
	如果是从NtoS的最后一个人， 就可以释放桥这个资源了
	 */
	if(countNS == 0)
		V(bridge);
	V(mutexNS);

}

```
