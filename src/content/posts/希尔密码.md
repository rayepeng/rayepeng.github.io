# 约定
希尔密码常使用Z26字母表大家都知道最小的质数是2, 1 既不是质数也不是合数. 在此我们定义1对任何质数的模逆为其本身. 因为对于任意质数n, 有: 1*1 mod n = 1 的. 也应该是很好理解的.

# 加密原理
加密者在对明文加密前会选择一个加密秘匙, 这个秘匙最终会以一个m矩阵的形式参与到加密算法中的. 在加密者选定了加密秘匙后, m便得到了确定,这时,加密者将明文按m个字母一组的形式分成多组, 最后一组不足m个字母的按特定的方式补齐. 这样就形成了很多组由m个字母组成的单个向量, 然后对每一个m阶向量, 我们用它去乘以确定好了的秘匙.
用公式体现如下
 [A1,A2,A3 ... Am] * M = [B1,B2,B3 ... Bm]

## 最小公倍数法

### 如何消掉分母

设a为明文中的一个字母. x 为 需要对当前的M^-1乘以的倍数. t为任意整数.
  
  ax = a + 26t. 恒成立. ==>>   t = a(x-1)/26  . 
  要想t为整数, 则 x = 26p+1 .p >=1. 这里我们一般取p =1 即可. 因此 x = 27.(及字母表个数加一)

 要消掉分母, 我们必须乘以分母D(M)的倍数. 其中D(M)为M的行列式值.
  
之后每个数字加上26， 这样不会影响字母表中的排布， 同时消去了负数
