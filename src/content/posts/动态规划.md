最经典的背包问题，从n件物品中，每件物品重量是wi, 价值是vi，
要挑选出总重量不超过W，使得价值最大
```
int w[MAX_N];
int v[MAX_N];
int n, W;

int rec(int i, int j)
{
    int res = 0;
    if(i == n)
        res = 0;
    else if(j < w[i])
    {
        res = rec(i+1, j);
    }
    else
    {
        res = max(rec(i+1, j), rec(i+1, j-w[i]) + v[i] );
    }
    return res;
}
```
>大概解释一下，我们设想一下，物品是一件件地挑选出来，在决定是否挑选第i件物品的时候，我们必须知道还有多少容量可供我们挑选。所以函数的两个参数就是如此，在决定是否挑选第i件物品的时候，我们要看这个i是不是==n， 因为计数是从0开始的，如果都等于n了，那早都挑完了。如果不是的话，那就要看是不是能挑，能挑的话我还需要犹豫一下，到底选不选呢，那就两种方式都尝试一下吧
