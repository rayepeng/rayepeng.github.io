## 写在前面
建议在编译内核之前了解一下内核的目录结构， 这样至少不会被绕晕

 
## 下载内核源码

> sudo apt search linux-source

![搜索源码包](https://upload-images.jianshu.io/upload_images/10651191-4467266030f97cf3.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

下载源码

> sudo apt install linux-source-4.15.0

这样就下载了源码包了

会直接放到这个目录下来
![默认下载位置](https://upload-images.jianshu.io/upload_images/10651191-385057e126a1685d.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

我直接解压到了自己的用户目录下

解压命令
>tar -xvf linux-source-4.15.0.tar.bz2 -C ~

最新版的tar命令可以智能的识别压缩的算法

进入目录之前，做一件事情

>sudo chmod 777  -R linux.source-4.15.0

省去后面不必要的权限麻烦

## 编写自定义函数

进入到 kernel 目录下

![kernel目录](https://upload-images.jianshu.io/upload_images/10651191-ae63eccb5d9789d7.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

执行
> vim sys.c

直接按 G 跳到文件末尾， 然后按 O 在最后一行的上一行添加代码， 进入编辑模式

```
asmlinkage long sys_helloworld(void){

    printk( "helloworld!");

    return 1;

}
```
![vim sys.c](https://upload-images.jianshu.io/upload_images/10651191-ccae95779129ef4a.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)
