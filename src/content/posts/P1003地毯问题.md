题目的意思。输入如下
3
1 0 2 3
0 2 3 3
2 1 3 3
2 2

输出如下
3

题目的要求如图：
![image.png](https://upload-images.jianshu.io/upload_images/10651191-004794b59ff3203b.png?imageMogr2/auto-orient/strip%7CimageView2/2/w/1240)

输入的第一行代表的是地毯的数目
接下来三行就是每个地毯放置的坐标位置
以及它们的长度和宽度
