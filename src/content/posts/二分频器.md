首先明白， 二分频分的是输入时钟的频率， 即CLK的频率。

每次在CLK的上升沿或者下降沿，让输出Q翻转

```
module div_2(q, clk, reset);

output q;
input reset;
input clk;
reg q;

always @(posedge clk or posedge reset)
	if(reset)
		q<=1'b0;
	else
		q<=~q;

endmodule

```
